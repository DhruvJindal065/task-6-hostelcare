NOTE:
This is a front-end HTML/CSS implementation. Forms are visual only and do not submit data to a backend.

TASK 6 - THREE IMPLEMENTED FEATURES (JavaScript in script.js):
1. Contact form validation: name, room number, service and message are checked
   with inline error messages before a request can be submitted.
2. Saved service requests: valid submissions are stored in the browser
   (localStorage), listed under "Your saved requests" on the Contact page,
   and can be deleted individually.
3. Login validation and password toggle: email/username and password are
   validated, and the Show/Hide button reveals or masks the password.

NOTE: The front-end has no server. Saved requests stay in the browser that
submitted them, and login does not authenticate against a database.
